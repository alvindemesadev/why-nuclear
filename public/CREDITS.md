# Image credits & licenses — Why Nuclear

Every image below is free to use with attribution. All are hosted on Wikimedia Commons;
none require payment or registration.

**Quick download:** `curl -L "https://commons.wikimedia.org/wiki/Special:FilePath/<FILENAME>" -o <filename>`
(`Special:FilePath` always redirects to the original file — no need to guess the hashed
`upload.wikimedia.org` path.)

**Attribution rules:** CC-BY images require author credit + license link (+ note if you
changed the image). CC BY-SA additionally requires any derived work to be shared under the
same license — fine for a website, just keep the credit lines below. Public-domain images
need no attribution, but crediting is still polite. A single credits block in the site
footer can hold all lines.
